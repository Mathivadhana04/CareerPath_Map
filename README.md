# Career_RoadMap

An AI-powered Career Roadmap Generator built with React.js + Spring Boot + Groq LLM.

## Features
- 🔍 Search any engineering role
- 🤖 AI-generated skill flowcharts (Groq LLM)
- 🗺️ Interactive React Flow diagrams
- 📖 Click-to-view detailed syllabus
- ✅ Progress tracking with localStorage

## Tech Stack
- **Frontend:** React.js + Vite + Tailwind CSS + React Flow
- **Backend:** Spring Boot (Java 17) + Maven
- **AI:** Groq API (llama-3.3-70b-versatile)

## Run Locally

### Backend
```bash
cd backend
mvn spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173
